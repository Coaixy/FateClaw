# 奇门遁甲排盘

按指定时间生成时家奇门拆补盘，返回排局、值符值使、天地盘、八门九星八神、马星、旬空、门迫击刑、长生运。基于 `kinqimen`（底层 tyme4ts），本地计算，无网络依赖。

## 使用流程

1. 从用户消息中提取时间（默认当前时间）
2. 调用 `load_skill` 加载本 skill
3. 用 `run_skill_script` 执行 `paipan.js`

## 调用方式

加载：

```text
load_skill({ skill_name: "qimen-paipan" })
```

当前时间起盘：

```text
run_skill_script({
  skill_name: "qimen-paipan",
  script: "paipan.js",
  stdin: "{}"
})
```

指定时间起盘：

```text
run_skill_script({
  skill_name: "qimen-paipan",
  script: "paipan.js",
  stdin: JSON.stringify({ solarDate: "2026-04-17", hour: 14, minute: 30 })
})
```

## 参数

| 参数 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| solarDate | string | 否 | 当前日期 | 阳历 YYYY-MM-DD |
| hour | integer | 否 | 当前时 | 0-23 |
| minute | integer | 否 | 0 或当前分 | 0-59 |

`solarDate` 和 `hour` 必须同时传入，或都不传（用当前时间）。

## 返回结构

```json
{
  "排盘方式": "拆补",
  "干支": "丙午年壬辰月辛酉日乙未时",
  "旬首": "甲午",
  "旬空": { "日空": "子丑", "时空": "辰巳" },
  "局日": "丙辛日",
  "排局": "阳七局下",
  "节气": "清明",
  "值符值使": {
    "值符天干": ["甲午","辛"],
    "值符星宫": ["蓬","乾"],
    "值使门宫": ["休","坤"]
  },
  "天乙": "辛",
  "天盘": { "乾":"辛","坎":"己","艮":"癸","震":"丁","巽":"庚","离":"壬","坤":"戊","兑":"乙","中":"丙" },
  "地盘": { ... },
  "门":   { "坤":"休","兑":"生","乾":"伤","坎":"杜","艮":"景","震":"死","巽":"惊","离":"开" },
  "星":   { "乾":"蓬","坎":"任",... },
  "神":   { "乾":"符","坎":"蛇",... },
  "暗干": { ... },
  "马星": { "天马":"申","丁马":"巳","驿马":"巳" },
  "长生运": { "天盘": {...}, "地盘": {...} },
  "门迫":   [ { "门":"...", "宫":"...", "门五行":"...", "宫五行":"..." } ],
  "击刑":   [ { "宫1":"...", "宫2":"...", "类型":"..." } ]
}
```

- **排局**：如 "阳七局下" = 阳遁七局下元
- **天盘/地盘**：九宫各自落的天干
- **门/星/神**：八宫的八门、九星、八神布局（中宫不落门星神）
- **暗干**：九宫暗藏天干
- **门迫**：门受宫克的不利格局
- **击刑**：宫位相刑

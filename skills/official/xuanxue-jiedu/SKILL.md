# 玄学解读

调用专业玄学模型，对各类玄学内容进行深度解读。

## 触发条件（满足至少一条才调用）

- 排盘 skill 返回数据后，需要自动解读
- 用户**明确给出**八字、卦象、星盘等数据，并**明确要求**分析
- 用户**明确描述**风水布局、手相面相等，并**明确要求**点评
- 用户**明确询问**择日、姓名学等玄学问题
- 用户**明确给出**塔罗牌面，并**要求**解读

## 禁止调用的情形

以下情况**禁止使用**本 skill：

- 日常闲聊、打招呼（如"你好""在吗"）
- 普通问题咨询（如"推荐个餐厅""帮我算个数学题"）
- 用户没有提供任何玄学数据，也没有明确占卜/命理请求
- 用户随口提及玄学词汇但未要求分析（如"听说今天宜出行""我属蛇"）
- 用户讨论/质疑玄学话题，但未要求具体解读
- 扮演角色、讲故事、做游戏等娱乐请求

**原则：宁可漏过，不要误判。除非用户明确要求解读，否则一律不调用。**

## 使用步骤

**Step 1**：确认满足触发条件，否则不调用本 skill。

**Step 2**：如果本轮已有官方排盘 artifact、activeBoardContext 或历史 toolContext，`content` 可省略，由运行时注入确定性 AI 摘要。

**Step 3**：提炼用户的具体问题（`question`），以及术数类别（`category`，如"八字""六爻""紫微"等）。

**Step 4**：通过统一工具入口 `interpret_xuanxue` 执行，不要改走其他脚本入口。

**Step 5**：将解读结果直接回复用户。

## 调用方式

```js
// 统一入口：直接调用 interpret_xuanxue 工具（会自动注入用户知识库内容）
interpret_xuanxue({
  content_source: "skill",
  question: "用户的具体问题",
  category: "八字"
})
```

## 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | string | 否 | 通常省略。运行时会从官方排盘 artifact、activeBoardContext 或历史 toolContext 注入确定性 AI 摘要；不要在工具参数里复制大段 JSON 或盘面文本 |
| question | string | 否 | 用户的具体问题，帮助聚焦解读方向 |
| category | string | 否 | 术数类别（如"八字""六爻""紫微""塔罗""风水"等），提供后解读更精准 |
| extra_context | string | 否 | 额外的解读参考资料。通过 `interpret_xuanxue` 工具调用时会自动注入用户知识库内容，无需手动传入 |

## 注意事项

- 系统排盘/手动排盘时优先省略 `content`，不要把大段原始 JSON 复制进 tool call
- 用户自贴时通过专用协议入口传入；普通聊天里的外部贴盘不走本工具的 `content_source="user"`
- **有排盘数据时，包含完整盘面信息**
- `category` 非必填，但提供后能让模型更精准定位

## 输出格式

| 字段 | 类型 | 说明 |
|------|------|------|
| interpretation | string | 解读正文（自然语言） |
| partial | boolean | 可选，`true` 表示因超时被截断，输出不完整 |

`partial=true` 时应告知用户解读可能不完整，建议重试。
